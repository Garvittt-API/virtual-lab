# Interactive laboratory milestone (partial)

The guided three-experiment runner now accepts student-entered volumes in mL or L and requires the correct named source, destination, stock or reaction for each step. Neutralization, ideal AgCl precipitation and salt dilution run from actual vessel contents. The guided sequence still prescribes the operation and apparatus; arbitrary workflows are not yet guided. Observations and undo/redo remain in the existing guided session. A selected quantity can leave a later step impossible; undo allows correction. A zero-reactant reaction completes without reaction in the underlying ideal model. Existing version-1 guided saves remain readable, with no schema migration. The old preset `next` command is retained for compatibility.

Free exploration starts with an empty bench using the same `execute` vessel engine. Place up to 12 registry objects by ID and position, select, move, rotate and remove empty/disconnected equipment. Add stocks, transfer liquids, mix, run neutralization or AgCl precipitation, inspect moles, molarity, volumes and settled solids. Free notebook records workspace events and separate observations, exports text, and maintains 50 undo/redo snapshots of workspace actions; notes do not undo. Reset is undoable but clears the current event history. Persisted version-1 free session uses `materia-free-v1`; it does not overwrite other activities. Invalid saved data falls back to an empty session; no cross-activity migration is attempted. Export reflects current state/history, not events undone or cleared.

Engine constraints enforce stock compatibility, capacity, available liquid and supported reactions; equipment without an operation may still show a control but attempting it returns an error. Placement uses simple distance checks, not geometric collision detection, and movement does not check overlap. Connection commands exist at engine level but are not exposed in free UI. No heating, gas, balances, pH meter, disposal, temperature, mass entry, mole entry, custom concentration, instrument measurement uncertainty or substance state changes are implemented. Existing activity screens and calculation runner retain separate models, notebooks and persistence; there is no unified assessment/notebook or migration of oxygen or legacy neutralization.

Chemistry assumes instantaneous ideal mixing, additive volumes, complete conversion and no equilibrium/kinetics; AgCl ignores Ksp and settled solids are excluded from transfers. Solvent mass is not tracked, nor is reaction temperature. These are software-tested models, not independently scientifically reviewed or instructions for a physical laboratory. See UNIFIED_SIMULATION.md for detailed assumptions.

Verification: terminal tests, lint, limited JavaScript typecheck, production build and npm audit. React/Three code is not typechecked; the 3D scene, layout, mobile interaction, and storage behavior have not been tested in a browser. Test manually with the README local startup steps, especially free-mode initial empty scene, selecting and dragging multiple objects, rotating, invalid operations, undo/redo, reload, export, all guided workflows, and mobile navigation.
