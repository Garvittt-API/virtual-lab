# Scientific validation scope

Authored setup is constructed with the same equipment registry, stock definitions, connection engine, and workspace validator used by the workbench. Validation checks registered IDs, apparatus positions and limits, compatible port connections, starting chemical amounts and vessel capacity, declared allowlisted commands, and reachability of each sequential command from the declared starting state. Reaction definitions are validated by the existing stoichiometric reaction validator. Measurement declarations are limited to implemented volume, dissolved concentration, and gas-inventory readings. At least one scientific assumption and a safety statement are required.

The current generic authored reaction commands model neutralization and AgCl precipitation. The oxygen-generation experiment remains a trusted built-in protocol because its staged heating, gas collection, and protocol metadata are not yet described by the generic authored command format. The generic authoring format does not claim a calculated pH result for custom neutralization manifests. Completion currently means that the declared instruction list has been completed; richer observation/measurement-gated completion policies are future work. Titration, arbitrary reaction authoring, thermal effects, activity corrections, and new chemical properties are deliberately excluded until their scientific models and workflows exist.

Validation establishes compatibility with the implemented idealized deterministic model. It does not establish experimental safety, empirical accuracy, or review by a qualified chemistry educator.
